# Daily proof exports

Place exports under a directory named for the mathematical source. Each Lean
file must cite the human authors, title, year, DOI (or arXiv ID or book ISBN),
and theorem or section in its module docstring. Record unresolved identifiers
in [CITATIONS-TODO.md](../../CITATIONS-TODO.md).

Keep a receipt with each proof. Include the generating model, attempt ID, Git
base commit, and kernel check with its command, toolchain, result, and axiom
dependencies. Use a separate receipt for each attempt that supplies a proof.

See [Attribution](../../ATTRIBUTION.md) for the source index.
