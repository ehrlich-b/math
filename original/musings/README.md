# Musings

Exploratory; not peer reviewed. These are Bryan Ehrlich's notebook results.

- [Rational clocks](RationalClockResearch.lean) collects the exact classes
  for coefficients 1 and 3, the uniform bound for positive coefficients, and
  the 2-adic conjugacy and invariant-measure results.
- [Threshold traps](BMO5TrapDepth.lean) proves a residue-class count and
  unbounded stopping depth among valid starting states for the shifted
  recurrence. The halting question for the distinguished orbit is open.
  The recurrence comes from the [bbchallenge Beaver Math Olympiad, Problem 5](https://wiki.bbchallenge.org/wiki/Beaver_Math_Olympiad#5._1RB0LD_1LC0RA_1RA1LB_1LA1LE_1RF0LC_---0RE_(bbch)).
- [Finite observer capacity](ObserverCapacity.lean) bounds survival in a
  finite-state model with finite observer memory. The
  [examples](ObserverCapacityInitialExamples.lean) check the role of initial
  correlation between memory and state.
